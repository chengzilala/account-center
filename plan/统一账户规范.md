# 统一账户规范（v0.2）

> **状态**：已定稿待实现（2026-10-23）。本文与 [接入契约.md](接入契约.md) 一起，是账户中心的**实现依据**。
> **唯一需求源**仍是 [RPD_需求文档.md](RPD_需求文档.md)；本文负责把「身份怎么定」说死，契约负责把「接口怎么调」说死。
> **运行环境**：与奶茶项目同台腾讯云轻量服务器（Node 常驻 + 反向代理 + HTTPS），存储首期用单机 JSON 文件。本文的规则**不绑定**具体平台。

---

## 1 一句话

**uid 是「人」，邮箱 / 手机号 / 账户码 / 第三方 / openid / 6 位码 都是「钥匙」；一把钥匙只开一个 uid，一个 uid 可以有很多把钥匙。**

账户中心只回答两件事：你是谁、你能进哪个作品。第三方 Key 和业务数据不进来。

---

## 2 名词

| 名词 | 含义 | 存放 |
|---|---|---|
| **uid** | 一个人的永久编号，全站唯一 | `ac_users.uid` |
| **钥匙** | 能证明「你是这个 uid」的凭据 | `ac_identities` |
| **会话** | 一次登录换来的登录态 | `ac_sessions` |
| **Token** | 会话的凭证字符串，作品侧带着它调接口 | 用户浏览器 localStorage |
| **作品** | 需要识别用户的站点 / 应用 | `ac_products` |

---

## 3 身份规则

### 3.1 uid 生成

- 格式：`u_` + 16 位小写十六进制（8 字节 CSPRNG），例：`u_9f3c1a7b2e5d8046`。
- 只由服务端生成，客户端不可指定。
- `ac_users._id` 就是 uid，天然防重。

### 3.2 钥匙类型

| 类型 | 钥匙 ID 格式 | 来源 | 备注 |
|---|---|---|---|
| 邮箱 | `email:<邮箱小写>` | 用户输入 + 验证码 | 邮箱统一转小写、去首尾空格 |
| 账户码 | `device:<32 位小写 hex>` | 微信悦读现有账户码 | **等同密码**，严格限流 |
| 微信 | `wx:<openid>` | 小程序服务端上下文 | 仅小程序内部可用（P1） |
| 第三方 OAuth | `oauth:<provider>:<id>` | GitHub / Gitee / Microsoft 授权回调 | 已可用；`provider` ∈ `github` / `gitee` / `microsoft`；微信 / Google 仍 P1 |
| 手机号 | `phone:<11 位数字>` | 短信验证码（阿里云短信认证） | 已可用；只支持中国大陆手机号，页面显示 `138****8000` |

### 3.3 绑定规则

1. 一个 uid 可以有多把钥匙；**一把钥匙只能属于一个 uid**。
2. 首次用某钥匙登录：
   - 钥匙不存在 → 新建 uid，并把钥匙指向它（新用户）；
   - 钥匙已存在 → 直接登录它指向的 uid（老用户）。
3. 已登录状态下绑定新钥匙（如加邮箱）：
   - 新钥匙没被占用 → 绑到当前 uid；
   - 新钥匙已被别的 uid 占用 → **返回冲突，不自动合并**，由用户决定用哪把登录。
4. 解绑只删这一把钥匙，不删 uid、不影响其他钥匙。
5. 不允许「合并两个 uid」的自动逻辑；首期只提示。

### 3.4 注销

- 用户主动注销 → `ac_users.status = 'deleted'`，删除该 uid 的全部钥匙，撤销全部会话。
- 审计日志保留（只记 uid 和动作，不留邮箱明文）。
- 注销后同一邮箱再登录 = 全新 uid，旧数据不找回（页面必须写清楚）。

### 3.5 老账户（微信悦读）

- `deviceId`（32 位账户码）继续是微信悦读的账号，`wre_users` **一个字段都不改**。
- 账户中心只新增 `device:<账户码> → uid` 映射。
- 惰性绑定：老用户第一次在账户中心登录时，把当前账户码绑到 uid；不批量迁移。

## 4 登录方式

| 方式 | 流程 | 有效期 | 关键约束 |
|---|---|---|---|
| 邮箱验证码 | 输邮箱 → 收 6 位数字 → 验码 → 查/建 `email:` 钥匙 → 建会话 | 码 10 分钟 | 同邮箱 60 秒可重发；码最多试 5 次 |
| 账户码 | 粘贴 32 位码 → 查/建 `device:` 钥匙 → 建会话 | — | 连续失败 10 次锁 15 分钟 |
| 6 位码 | 已登录设备生成 → 另一台输入 → 换 uid → 建会话 | 码 10 分钟、一次性 | 失败 5 次作废 |
| 小程序 openid | 云函数从调用上下文取 openid → 查/建 `wx:` 钥匙 | — | P1，个人小程序不能用 web-view |
| 第三方 OAuth | 平台授权回调 → 取平台账户标识 → 查/建 `oauth:` 钥匙 → 建会话 | state 10 分钟、一次性；回页面 code 5 分钟 | GitHub / Gitee / Microsoft 已可用；已验证邮箱已注册时**不自动合并**，提示先用邮箱登录再绑定 |
| 手机短信 | 输手机号 → 过图形验证码 → 收短信码 → 验码 → 查/建 `phone:` 钥匙 → 建会话 | 码 10 分钟 | 已可用；发送前必须过图形验证码；同号 1 次/分钟、5 次/小时、10 次/天；绑定走账户页，不自动合并 |

**6 位码不是账号**：它只是一次性的「接力棒」，用完即废，不能当长期登录方式。

## 5 会话与 Token

| 项 | 规则 |
|---|---|
| Token 形态 | 32 字节随机串的 base64url，**不透明**，不含任何用户信息 |
| 服务端存储 | 只存 `sha256(token)`，不存明文 |
| 传递方式 | 请求头 `Authorization: Bearer <token>`；**不用 Cookie**（跨域不共享登录态） |
| 有效期 | 30 天；剩余不足 7 天时自动续到 30 天 |
| 退出当前 | 删除本条会话，Token 立即失效 |
| 退出全部 | 删除该 uid 全部会话 |
| 并发 | 同一 uid 允许多设备同时在线，上限 10 条会话，超出踢最早的 |

会话记录字段：`sid`、`uid`、`appId`、`deviceId`、`tokenHash`、`createdAt`、`lastSeenAt`、`expiresAt`、`revoked`、`ipHash`、`ua`。

> 安全口径：服务端只认 Token 的哈希，**数据库泄露也拿不到可用 Token**；`ipHash` 只用于风控，不存明文 IP。

## 6 数据归属（铁律）

| 数据 | 归谁 | 说明 |
|---|---|---|
| uid、钥匙、会话、作品开通状态 | **账户中心** | `ac_*` 集合 |
| 微信读书 Key、DeepSeek Key | 各作品 | 不进账户中心 |
| 高驰 Token、跑步数据 | 高驰看板 | 不进账户中心 |
| 书架、笔记、阅读人格 | 微信悦读 | 不进账户中心 |
| 昵称 / 头像 | 账户中心只存展示用副本 | 各作品可覆盖显示 |

作品侧**只允许存 uid**，不允许存邮箱、账户码、Token 之外的钥匙。

---

## 7 安全红线

1. 全程 HTTPS；账户码与 Token 视同密码。
2. 6 位码 10 分钟、一次性；邮箱验证码 10 分钟、最多 5 次尝试。
3. 所有发码 / 登录接口必须限流（见契约 §4），超限返回 `429`。
4. 密钥（Token 签名盐、邮件通道密钥）只放服务器环境变量（systemd EnvironmentFile），**不入仓库、不写日志**。
5. 日志与审计脱敏：邮箱只记掩码（`a***@qq.com`），账户码只记前 4 + 后 4 位，Token 一律不记。
6. 管理后台仅 `admin` uid 可进；首个 admin 手动写配置，不走注册。
7. 任何「合并 / 迁移」动作必须人工确认，不做自动合并。

## 8 命名约定

- 集合：`ac_` 前缀（`ac_users` / `ac_identities` / `ac_sessions` / `ac_login_codes` / `ac_products` / `ac_entitlements` / `ac_audit_logs`）。
- 接口：单进程 `server.js`，统一 `POST /accountCenter`，按 `action` 路由。
- 页面 CSS：`ac-` 前缀；文件名英文小写加连字符。
- 时间：统一存毫秒时间戳（`createdAt` / `expiresAt`），展示时再格式化。

## 9 集合与字段

| 集合 | `_id` | 关键字段 |
|---|---|---|
| `ac_users` | uid | `uid`、`nickname`、`avatar`、`status`（active/deleted）、`createdAt`、`updatedAt` |
| `ac_identities` | 钥匙 ID | `uid`、`kind`（email/device/wx/oauth/phone）、`value`（邮箱存小写；账户码存原值；oauth 存平台账号名）、`provider`（仅 oauth）、`createdAt`、`lastUsedAt` |
| `ac_sessions` | sid | 见 §5 |
| `ac_login_codes` | 随机 | `kind`（email/transfer/oauth_state/oauth_login）、`codeHash`、`email`、`uid`、`provider`、`returnUrl`、`mode`、`isNew`、`expiresAt`、`used`、`attempts`、`createdAt` |
| `ac_products` | appId | `appId`、`name`、`url`、`status`、`createdAt` |
| `ac_entitlements` | `<uid>:<appId>` | `uid`、`appId`、`status`、`expiresAt` |
| `ac_audit_logs` | 随机 | `actorUid`、`action`、`target`、`ipHash`、`ua`、`createdAt` |

> 首期作品准入规则是「登录即可用」：登录成功后 `ac_entitlements` 不存在的作品，按 `active` 处理，不预写数据。

---

## 10 验收标准

1. 同一邮箱 + 同一账户码，登录后拿到**同一个 uid**。
2. Token 过期 / 退出后立即失效；退出全部后所有设备都要重新登录。
3. 数据库里查不到明文 Token、明文邮箱以外的敏感信息、完整账户码。
4. 邮箱验证码、账户码、6 位码三种方式都能独立完成登录。
5. 注销后钥匙清空、会话失效、同邮箱再登录得到新 uid。
