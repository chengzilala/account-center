# 接入契约（v0.5）

> **状态**：MVP 已实现（登录 / 会话 / 凭证 / 足迹 / 跨域票据；2026-10-27 更新）。实现依据 = 本文 + [统一账户规范.md](统一账户规范.md)。
> **一句话**：所有客户端只做一件事——`POST` 一个 JSON，里面用 `action` 说明要干什么；服务端统一返回 `{ ok, data }` 或 `{ ok: false, code, message }`。

---

## 1 传输方式

| 项 | 约定 |
|---|---|
| 地址 | `POST https://<账户中心域名>/accountCenter`（Node 常驻服务 `server.js`，Nginx/Caddy 反代；健康检查 `GET /healthz`） |
| 请求头 | `Content-Type: application/json` |
| 登录态 | `Authorization: Bearer <token>`（只有标注「需登录」的 action 才需要） |
| 请求体 | `{ "action": "auth.email.send", "email": "...", ... }`——**所有参数平铺在顶层**，不再套一层 |
| 跨域 | 服务端已支持 CORS：`OPTIONS` 预检 204；白名单由 `ALLOWED_ORIGINS` 控制（线上只填实际页面域名） |
| 字符集 | UTF-8；邮箱统一小写；参数去首尾空格 |

**为什么不用 REST 路径**：与微信悦读 `wereadProxy` 的 `action` 风格保持一致，一个函数一个入口，改动和部署都只动一处。

---

## 2 统一响应

成功：

```json
{ "ok": true, "data": { } }
```

失败：

```json
{ "ok": false, "code": "RATE_LIMITED", "message": "请求太频繁，请 60 秒后再试" }
```

规则：

- `message` 是**给用户看的中文**，可以直接展示。
- `code` 是**给程序判断的**，不随文案变化。
- HTTP 状态码同步：`200` 成功；`400/401/403/404/409/429/500` 对应失败。
- 不返回堆栈、不返回内部字段名。

---

## 3 错误码

| code | HTTP | 含义 | 页面建议处理 |
|---|---|---|---|
| `INVALID_PARAM` | 400 | 参数缺失或格式不对 | 提示具体哪一项 |
| `CODE_INVALID` | 400 | 验证码 / 6 位码错误 | 提示重试，剩余次数 |
| `CODE_EXPIRED` | 400 | 验证码过期或已使用 | 引导重新获取 |
| `KEY_TAKEN` | 409 | 这把钥匙已属于另一个 uid | 提示「该账户已属于另一个账号」，不自动合并 |
| `UNAUTHORIZED` | 401 | 未登录 / Token 无效 / 已退出 | 清本机 Token，跳登录页 |
| `FORBIDDEN` | 403 | 无权限（如非 admin） | 提示无权限 |
| `ACCOUNT_DELETED` | 403 | 账号已注销 | 提示重新登录 |
| `NOT_FOUND` | 404 | 资源不存在 | 提示刷新 |
| `RATE_LIMITED` | 429 | 触发限流或锁定 | 显示剩余等待时间 |
| `MAIL_FAILED` | 500 | 邮件通道发送失败 | 提示换邮箱或稍后重试 |
| `INTERNAL` | 500 | 服务端异常 | 提示稍后重试，日志留痕 |

## 4 接口清单（MVP）

> 「需登录」= 必须带 `Authorization: Bearer`。

### 4.1 `auth.email.send` — 发邮箱验证码

| 项 | 内容 |
|---|---|
| 入参 | `email` |
| 出参 | `{ expiresIn: 600, cooldown: 60, masked: "a***@qq.com" }` |
| 失败 | `INVALID_PARAM` / `RATE_LIMITED` / `MAIL_FAILED` |
| 限流 | 同邮箱 60 秒 1 次、1 小时 5 次、1 天 20 次；同 IP 1 小时 20 次 |

### 4.2 `auth.email.verify` — 验码登录 / 注册

| 项 | 内容 |
|---|---|
| 入参 | `email`、`code`（6 位数字）、`deviceId`（可选，本机账户码） |
| 出参 | `{ token, uid, isNew, expiresAt }` |
| 失败 | `CODE_INVALID` / `CODE_EXPIRED` / `RATE_LIMITED` |
| 附带动作 | 请求里带 `deviceId` 且未被占用时，自动绑一把 `device:` 钥匙（惰性迁移）；已被占用则**忽略**，不报错 |

### 4.3 `auth.accountCode.login` — 账户码登录

| 项 | 内容 |
|---|---|
| 入参 | `accountCode`（32 位十六进制） |
| 出参 | `{ token, uid, isNew, expiresAt }` |
| 失败 | `INVALID_PARAM` / `RATE_LIMITED` |
| 限流 | 同 IP 10 次 / 10 分钟；同账户码连续失败 10 次锁 15 分钟 |

### 4.4 `auth.code.start` — 生成 6 位码（需登录）

| 项 | 内容 |
|---|---|
| 入参 | 无 |
| 出参 | `{ code: "482913", expiresIn: 600 }` |
| 说明 | 一次性；生成新码时旧的立即作废 |

### 4.5 `auth.code.redeem` — 用 6 位码登录

| 项 | 内容 |
|---|---|
| 入参 | `code`、`deviceId`（可选） |
| 出参 | `{ token, uid, expiresAt }` |
| 失败 | `CODE_INVALID` / `CODE_EXPIRED` / `RATE_LIMITED` |
| 限流 | 同 IP 10 次 / 10 分钟；同一码失败 5 次作废 |

### 4.6 `me` — 当前用户（需登录）

| 项 | 内容 |
|---|---|
| 入参 | 无 |
| 出参 | `{ uid, nickname, avatar, emailMasked, phoneMasked, keys: [{ kind, provider, masked, createdAt, lastUsedAt }], createdAt }` |

> `keys` 只回掩码：邮箱 `a***@qq.com`，手机号 `138****8000`，账户码 `9f3c····8046`，第三方 `GitHub · octocat`。**任何接口都不回完整账户码。**
> `kind` 为 `email` / `phone` / `device` / `oauth`；`provider` 仅 `kind=oauth` 时有值（`github` / `gitee` / `microsoft`）。

### 4.7 `me.products` — 我的作品（需登录）

| 项 | 内容 |
|---|---|
| 入参 | 无 |
| 出参 | `{ products: [{ appId, name, url, status }] }` |
| 说明 | `ac_entitlements` 无记录时按 `active` 返回，对应「登录即可用」 |

### 4.8 `auth.logout` — 退出当前设备（需登录）

| 项 | 内容 |
|---|---|
| 入参 | 无 |
| 出参 | `{ ok: true }` |
| 说明 | 删除本条会话；本机 Token 由客户端清除 |

### 4.9 `auth.logoutAll` — 退出全部设备（需登录）

| 项 | 内容 |
|---|---|
| 入参 | 无 |
| 出参 | `{ revoked: 3 }` |

### 4.10 `account.delete` — 注销账户（需登录）

| 项 | 内容 |
|---|---|
| 入参 | `confirm: "注销"`（必须逐字一致） |
| 出参 | `{ deleted: true }` |
| 说明 | `ac_users.status = deleted`、删全部钥匙、撤销全部会话；不可恢复 |

### 4.11 `account.credential` — 账户凭证卡（需登录）

| 项 | 内容 |
|---|---|
| 入参 | 无 |
| 出参 | `{ uid, nickname, email, createdAt }` |
| 说明 | 只给本人生成凭证图片用，因此回**完整邮箱**；**仍不回完整账户码**；调用写审计 `account.credential` |

### 4.12 `track` — 作品行为上报（需登录）

| 项 | 内容 |
|---|---|
| 入参 | `productId`、`event`（`open` / `use` / `browse`）、`title`（可选）、`platform`（可选：`web` / `h5` / `miniprogram` / `plugin`）、`meta`（可选，仅短字符串键值）；`action` 固定为 `track`，**不要**用它传行为类型 |
| 出参 | `{ recorded: true }`；命中去重时多一个 `deduped: true` |
| 失败 | `INVALID_PARAM` / `RATE_LIMITED` / `UNAUTHORIZED` |
| 限流 | 同 uid 60 条 / 分钟；`event` 走白名单，未知直接忽略（仍返回 `recorded: true`） |
| 去重 | 同 uid + 同作品 + 同页面 / 动作，30 分钟内只落 1 条 |
| 说明 | 只记「做了什么」，不接收业务内容、第三方 Key、Token；写 `ac_audit_logs`（`scope = product` / `browse`） |

### 4.13 `me.activity` — 我的足迹（需登录）

| 项 | 内容 |
|---|---|
| 入参 | `range`（`7d` / `30d` / `90d`，默认 `30d`）、`scope`（`all` / `account` / `product` / `browse` / `security`）、`cursor`（可选）、`limit`（默认 10，最大 50） |
| 出参 | `{ items: [{ id, scope, action, title, productId, platform, createdAt }], nextCursor }` |
| 说明 | 只返回**本人**事件；`ip` 只回存在与否，不回哈希；`security` 类只回类型与时间 |

### 4.14 `me.activity.clear` — 清除行为记录（需登录）

| 项 | 内容 |
|---|---|
| 入参 | `scope`（`product` / `browse`，也接受 `all` = 两类一起清） |
| 出参 | `{ removed: 42 }` |
| 说明 | 只删本人 `product` / `browse` 类；`account` / `security` 不删；删除动作本身写一条审计 |

### 4.15 `auth.ticket.issue` — 签发跨域登录票据（需登录）

| 项 | 内容 |
|---|---|
| 入参 | `productId`、`returnUrl`（可选；该作品在 `ac_products` 登记了 `url` 时可省略，默认回登记地址） |
| 出参 | `{ ticket, expiresIn: 300, redirectUrl }` |
| 失败 | `INVALID_PARAM` / `UNAUTHORIZED` / `RATE_LIMITED` |
| 限流 | 同 uid 10 次 / 10 分钟 |
| 说明 | `ticket` 为 32 位十六进制，**5 分钟、一次一用**，服务端只存哈希；`redirectUrl` 是 `returnUrl` 追加 `ps_ticket` 参数后的完整地址，登录页直接跳转即可 |
| 域名校验 | `returnUrl` 站点必须是该作品在 `ac_products` 登记的域名（**登记的裸域允许 `www` 变体，其余必须完全一致**）；作品未登记时必须在 `ALLOWED_ORIGINS` 白名单内；只接受 `http(s)`，一律拒签其余地址（防开放跳转） |

### 4.16 `auth.ticket.redeem` — 用票据换 Token

| 项 | 内容 |
|---|---|
| 入参 | `ticket`（32 位十六进制） |
| 出参 | `{ token, uid, expiresAt, isNew: false }` |
| 失败 | `CODE_INVALID` / `CODE_EXPIRED` / `ACCOUNT_DELETED` / `RATE_LIMITED` |
| 限流 | 同 IP 30 次 / 10 分钟 |
| 说明 | 换完立即作废；签发的会话 `appId` = 签票时的 `productId`，有效期同普通会话（30 天） |

### 4.17 `account.profile` — 修改个人资料（需登录）

| 项 | 内容 |
|---|---|
| 入参 | `nickname`（1–20 字，去首尾空白）、`avatar`（可选，`data:image/(png\|jpeg\|webp);base64,…`，≤ 48KB；传空串表示清除头像）；两者至少要传一个 |
| 出参 | `{ nickname, avatar }` |
| 失败 | `INVALID_PARAM` / `AVATAR_TOO_LARGE` / `UNAUTHORIZED` |
| 说明 | 邮箱、uid 是登录钥匙，不在此接口修改；头像只接受图片 dataURL（客户端先用 canvas 压到 160×160 JPEG 再传）；写审计 `account.profile` |

### 4.18 第三方登录（GitHub / Gitee / Microsoft，已实现）

> 回调是浏览器的 GET 跳转，不走 `POST /accountCenter`；页面最终只拿到一次性 code，Token 不经过地址栏。

#### 4.18.1 `auth.oauth.providers` — 查询已启用的登录方式（公开）

| 项 | 内容 |
|---|---|
| 入参 | 无 |
| 出参 | `{ providers: [{ id, name }] }` |
| 说明 | 只返回服务端配好 `Client ID` / `Client Secret` 的平台；没配置的平台连按钮都不出现 |

#### 4.18.2 `auth.oauth.start` — 取平台授权地址

| 项 | 内容 |
|---|---|
| 入参 | `provider`（`github` / `gitee` / `microsoft`）、`mode`（`login` 默认，`bind` 绑定）、`returnUrl` |
| 出参 | `{ provider, url }`；前端直接 `location.href = url` |
| 失败 | `INVALID_PARAM`（平台未启用 / returnUrl 不合法）、`UNAUTHORIZED`（`mode=bind` 未登录）、`RATE_LIMITED` |
| 限制 | 同 IP 20 次 / 10 分钟；`returnUrl` 只允许本站 `login.html` / `account.html`（防开放跳转） |
| 说明 | 生成 32 位 `state`，以哈希形式存 `ac_login_codes`（`kind=oauth_state`，10 分钟、一次性），并记住回跳页与绑定目标 uid |

#### 4.18.3 `GET /oauth/<provider>/callback` — 平台回跳（浏览器跳转）

| 项 | 内容 |
|---|---|
| 入参 | querystring：`code`、`state` |
| 成功 | 302 → `returnUrl?oauth_code=<一次性码>`；`mode=bind` 时 → `returnUrl?oauth_bound=<provider>` |
| 失败 | 302 → `returnUrl?oauth_error=<denied / state / provider / email_exists / key_taken / not_configured / internal>` |
| 说明 | 校验 `state` 后 code 换平台用户资料。`login`：查 / 建 `oauth:<平台>:<平台用户 ID>`；若平台返回的**已验证邮箱**已注册，不建号、回 `email_exists`（提示先用邮箱登录再绑定）。`bind`：把钥匙挂到当前 uid，已被他人占用回 `key_taken`，不抢钥匙 |

#### 4.18.4 `auth.oauth.exchange` — 一次性码换 Token

| 项 | 内容 |
|---|---|
| 入参 | `code`（32 位十六进制）、可选 `deviceId` |
| 出参 | `{ token, uid, expiresAt, isNew }` |
| 失败 | `CODE_INVALID` / `CODE_EXPIRED` / `ACCOUNT_DELETED` |
| 限制 | 同 IP 30 次 / 10 分钟；code 5 分钟、一次性 |
| 说明 | 审计记 `oauth` 登录（新账户记 `account.create`）；绑定记 `account.bind` |

### 4.19 手机号验证码（短信认证）

> 走阿里云「短信认证」（号码认证服务，系统预置签名 + 模板），个人实名可用。核验接口免费，按运营商回执计费。
> **未配置短信环境变量时整条链路自动关闭**：`auth.methods` 返回 `sms: false`，页面不出现手机号入口，`auth.sms.*` 直接回 `SMS_DISABLED`。
> 防刷：发送前必须先过图形验证码，再叠加手机号 + IP 多级限流。

#### 4.19.1 `auth.methods` — 登录方式能力（公开）

| 项 | 内容 |
|---|---|
| 入参 | 无 |
| 出参 | `{ sms: boolean, smsProvider: 'aliyun' \| '' }` |
| 说明 | 页面据此决定是否显示「手机号验证码登录」入口；第三方平台继续用 `auth.oauth.providers` |

#### 4.19.2 `auth.captcha` — 取图形验证码（公开）

| 项 | 内容 |
|---|---|
| 入参 | 无 |
| 出参 | `{ id, svg, expiresIn }`；`id` 为 24 位十六进制，`svg` 直接塞进容器 |
| 失败 | `RATE_LIMITED` |
| 限流 | 同 IP 60 次 / 10 分钟 |
| 说明 | 4 位数字，2 分钟、一次性，答错 5 次作废；答案只存哈希（`ac_login_codes`，`kind=captcha`）；SVG 用点阵方块绘制，不含文字节点 |

#### 4.19.3 `auth.sms.send` — 发送短信验证码（公开）

| 项 | 内容 |
|---|---|
| 入参 | `phone`（11 位，允许 `+86` / 空格 / 横线）、`captchaId`、`captchaCode` |
| 出参 | `{ expiresIn: 600, cooldown: 60, masked }` |
| 失败 | `SMS_DISABLED`、`INVALID_PARAM`（手机号不合法）、`CAPTCHA_INVALID`（图形码错 / 过期）、`SMS_FAILED`（服务商异常）、`RATE_LIMITED`（带 `retryAfter`） |
| 限流 | 图形码：同 IP 20 次 / 10 分钟；同一号码 1 次 / 分钟、5 次 / 小时、10 次 / 天；同 IP 20 次 / 小时、50 次 / 天 |
| 说明 | 先消费图形验证码，通过后才调用短信服务商；验证码 10 分钟有效；写审计 `sms.send`（目标只记掩码） |

#### 4.19.4 `auth.sms.verify` — 校验验证码并登录 / 绑定

| 项 | 内容 |
|---|---|
| 入参 | `phone`、`code`（6 位）、可选 `deviceId`、可选 `bind: true` |
| 出参 | 登录：`{ token, uid, expiresAt, isNew }`；绑定：`{ bound: true, already, masked }` |
| 失败 | `SMS_DISABLED`、`INVALID_PARAM`、`CODE_INVALID`（验证码错 / 过期）、`SMS_FAILED`、`PHONE_TAKEN`（该号已绑定别的账户）、`UNAUTHORIZED`（`bind` 未登录）、`RATE_LIMITED` |
| 限流 | 同 IP 30 次 / 10 分钟；同一号码 10 次 / 10 分钟 |
| 说明 | 默认按登录处理：钥匙 `phone:<11 位>` 没绑过就建号，绑过就落到同一 uid，并顺带绑定本机账户码。`bind: true` 时把手机号挂到当前 Token 的 uid，**不自动合并账户**；号码属于已注销账户时视为未绑定。写审计 `account.create` / `auth.login` / `account.bind` |

| 入参 | `qrId`、`deviceId`（可选） |
| 出参 | `{ status }`：`pending` / `approved` / `denied` / `expired` / `used`；`approved` 时带 `{ token, expiresAt, uid, nickname, avatar }` |
| 限流 | 同 IP 600 次 / 10 分钟（页面每 2 秒轮询一次） |
| 说明 | **一次性**：取到 Token 后这条码标记 `claimed`，再轮询回 `used`；拒绝 / 过期永远拿不到 Token；登录成功写审计 `auth.qr.login` |

### 4.25 `account.code.generate` — 生成 / 重置账户码（需登录）

| 项 | 内容 |
|---|---|
| 入参 | 无 |
| 出参 | `{ accountCode: "32 位十六进制" }` |
| 限流 | 同 uid 5 次 / 10 分钟 |
| 说明 | 服务端随机生成，**完整值只在这里返回一次**（页面当场展示 + 复制，之后 `me` 只回掩码）；同一账户已有账户码时先删旧的再写新的，**旧码立即失效**；写审计 `account.code`。生成后可直接在登录页「账户码登录」里粘贴使用 |

## 5 作品侧 SDK 契约（`sdk/ps-auth.js`）

作品只通过这一个文件接账户中心，**不直接写接口地址**。

```js
PSAuth.init({ apiBase: 'https://<账户中心域名>', productId: 'personal-site' })

await PSAuth.getUser()           // 未登录返回 null；已登录返回 { uid, nickname, avatar, emailMasked }
await PSAuth.requireLogin()      // 未登录则跳转登录页（带 returnUrl），登录后回来；返回 user
await PSAuth.logout()            // 清本机 Token + 调 auth.logout（并停用该域静默登录，直到手动登录）
await PSAuth.track({ ... })      // 行为上报（2026-10-28 起随「我的足迹」停用，接口保留、作品侧已不再调用）
```

约定：

- `init` 可选 `loginUrl`：登录页完整地址，用于「接口与页面不同端口 / 不同域名」（本机调试 8942 接口 + 18830 页面）；不填则用 `apiBase + loginPath`（默认 `/login.html`）。
- Token 存本机 `localStorage`，键名 `ps_token`（同域共用；不同域各存各的）。
- `init` 时若地址栏带 `ps_ticket`，会自动调 `auth.ticket.redeem` 换 Token，并立刻从地址栏抹掉参数；换票失败按未登录处理，不阻塞页面。
- **静默登录（2026-10-28 新增）**：`init` 时本域没有 Token，会跳一次 `apiBase + /sso.html?productId=&returnUrl=`；账户中心有登录态就签票带回（用户无感），没有就回跳 `?ps_sso=none`。同一域名 12 小时内最多试一次；`logout()` 会写 `ps_sso_off` 标记，避免被静默登录拉回，手动登录成功后自动解除。
- `requireLogin()` 跳 `loginUrl`（未传时 `{apiBase}/login.html`）并带上 `productId` + `returnUrl`；已登录直接返回 user，未登录跳转后返回 `null`。
- 配色**默认不用写代码**：账户中心按 `productId` 登记主题（`theme` / `accent`），登录页自动取用（`product.theme`）。`init` 的 `theme` / `accent` 只是**临时覆盖**（优先级最高），不传即按登记值。
- 登录页也可直接手拼：`login.html?productId=xxx&returnUrl=xxx&theme=dark&accent=%23d6402a`（`#` 要编码成 `%23`）。主题记在账户中心域本机，登录后进「我的账户」、协议页自动沿用。
- 每次 `getUser` 先看本机 Token，再调 `me` 校验；`401` / `ACCOUNT_DELETED` 时自动清 Token 并返回 `null`（网络错误会抛出，不误判为退出）。
- `track` 失败静默、绝不阻塞作品主流程；`event` 只填 `open` / `use` / `browse`；不传业务内容、第三方 Key、Token。
- SDK 不读、不传任何第三方 Key，只认 uid。
- 跨域作品（不同域名）统一走「跳转登录 + 一次性票据回跳」，不做共享 Cookie、不做 iframe。

## 6 服务端实现约定

| 项 | 约定 |
|---|---|
| 入口 | `cloud/functions/accountCenter/server.js`（生产）/ `dev-server.js`（本地，验证码打印终端） |
| 模块 | `app.js`（按 `action` 分发）、`lib/store-json.js`（JSON 存储）、`lib/mail-smtp.js`（SMTP 发信）、`lib/token.js`、`lib/rateLimit.js`、`lib/validate.js`、`lib/errors.js` |
| 未识别的 action | 返回 `INVALID_PARAM`，不抛异常 |
| 幂等 | `auth.email.send` 同邮箱 60 秒内重复调用直接返回上次结果，不重发 |
| 审计 | 登录成功/失败、绑定、解绑、退出全部、注销，写 `ac_audit_logs`（脱敏） |
| 行为记录 | 账户动作、作品上报、页面浏览、安全事件统一写 `ac_audit_logs`（扩展 `scope` / `source` / `platform` / `visibleToUser`），90 天清理；`product` / `browse` 可由本人清除 |
| 环境变量 | `TOKEN_PEPPER`（Token 哈希盐）、`SMTP_HOST/PORT/SECURE/USER/PASS`、`MAIL_FROM`、`DATA_FILE`、`ALLOWED_ORIGINS`、`PORT`；**只放 systemd EnvironmentFile** |
| 日志 | 统一前缀 `[accountCenter]`，不打印邮箱明文、账户码、Token |
